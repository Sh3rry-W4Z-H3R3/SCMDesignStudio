# SCM Studio Contact Page Documentation

## Overview

This documentation provides information about the contact page created for SCM Studio. The page has been designed to match the brand's visual identity and includes all requested elements.

## Files Included

- `contact.html` - The main HTML file containing the contact page structure and embedded CSS
- `contact_form.js` - JavaScript file for form validation and FAQ accordion functionality
- `images/logo.png` - Logo image used in the header and footer

## Features

1. **Brand-Consistent Design**

   - Deep purple gradient background with geometric patterns
   - Teal/turquoise accent colors for buttons and headings
   - Clean white text for readability
   - Modern, sleek look matching the homepage style

2. **Contact Information Section**

   - Email (primary contact method): hello@scmstudio.com
   - Phone number: +1 (234) 567-890
   - Social media links: Instagram, Pinterest, Spotify, LinkedIn

3. **Contact Form**

   - Standard fields: Name, Email, Phone (optional), Subject, Message
   - Form validation with error messages
   - Submit button in teal/green to match homepage buttons

4. **FAQ Section**

   - Accordion-style questions and answers
   - Relevant FAQs for a design agency
   - Expandable/collapsible for better user experience

5. **Responsive Design**
   - Adapts to different screen sizes
   - Mobile-friendly layout

## Implementation Notes

- The contact form includes client-side validation using JavaScript
- The FAQ section uses JavaScript for the accordion functionality
- All styling is included directly in the HTML file for simplicity
- The page uses Font Awesome for social media icons

## How to Use

1. Extract all files from the zip archive, maintaining the folder structure
2. Upload the files to your web server
3. Ensure the `contact_form.js` file is in the same directory as the HTML file
4. Update the contact information and FAQs as needed
5. Replace the logo image with your actual logo if needed

## Customization

You can easily customize the page by:

- Updating the contact information in the HTML file
- Modifying the FAQ questions and answers
- Adjusting the color scheme by changing the CSS variables at the top of the style section
- Adding or removing form fields as needed

## Browser Compatibility

The page has been designed to work with modern browsers including:

- Chrome
- Firefox
- Safari
- Edge
